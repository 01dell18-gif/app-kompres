FOLDER INSTALLERS - FJY CHANNEL KOMPRES (100% OFFLINE READY)
=============================================================

Folder ini berisi seluruh paket dan komponen aplikasi resmi yang dibutuhkan
untuk menjalankan aplikasi web FJY Channel Kompres di komputer Windows mana pun
secara mandiri tanpa memerlukan koneksi internet:

1. node.exe (v20.18.3 Portable)
   - Biner portabel Node.js resmi siap pakai tanpa instalasi (Zero-Install).
   - Memungkinkan jalankan.bat langsung meluncurkan server lokal dalam 0.1 detik
     tanpa memerlukan izin Administrator (UAC) dan tanpa mengubah PATH sistem.

2. node-v20.18.3-win-x64.zip
   - Arsip resmi Node.js Portable LTS jika node.exe perlu diekstrak ulang secara mandiri.

3. node-v24.22.2-x64.msi
   - Berkas instalasi resmi Windows MSI jika perangkat menginginkan instalasi permanen di sistem.

4. node_modules_offline.zip
   - Paket lengkap pustaka Node.js & Vite (offline packages) untuk kompilasi ulang jika folder dist dihapus.

Catatan:
Aplikasi ini 100% berjalan lokal di browser (client-side) tanpa pernah mengirim
atau mengunggah berkas apa pun ke server luar (Zero Egress).
