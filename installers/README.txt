FOLDER INSTALLERS - FJY CHANNEL KOMPRES
=========================================

Folder ini berisi berkas instalasi resmi yang diperlukan untuk menjalankan aplikasi web FJY Channel Kompres di komputer Windows:

1. node-v24.22.2-x64.msi
   - Installer resmi Node.js LTS (64-bit) untuk Windows.
   - Jika aplikasi dijalankan di komputer baru yang belum memiliki Node.js,
     skrip start.bat atau jalankan.bat akan otomatis mendeteksi dan
     memasang installer ini tanpa perlu mengunduh lagi dari internet.

Aplikasi ini 100% berjalan lokal di peramban (client-side) tanpa memerlukan koneksi internet setelah terpasang.
